# คู่มือการใช้งานระบบแดชบอร์ดรายได้และผลการดำเนินงาน (Reg.6 Revenue Dashboard)
**ฉบับผู้ใช้งานทั่วไป (End-User & Management Guide)**

---

## 🎯 1. ภาพรวมของระบบ (System Overview)
ระบบแดชบอร์ดนี้จัดทำขึ้นเพื่อติดตามผลประกอบการรายได้และค่าใช้จ่ายของ **สำนักงานไปรษณีย์เขต 6** อย่างแม่นยำและเรียลไทม์ โดยรวบรวมข้อมูลจากทุกแหล่งงาน (SAP, BI, รส.201, COD, e-Commerce, Fuze Post, สลากฯ, และ Pickup Service) มาวิเคราะห์และแสดงผลในหน้าจอเดียว

---

## 🧭 2. เมนูหลักและการนำทาง (Navigation Tabs)
เมื่อเข้าสู่ระบบ จะพบแท็บเปลี่ยนมุมมองหลักที่แถบด้านบน 3 มุมมอง:

| แท็บมุมมอง | วัตถุประสงค์การใช้งาน | ข้อมูลที่แสดง |
| :--- | :--- | :--- |
| **📊 ภาพรวมรายเดือน (Monthly)** | สรุปผลประกอบการภาพรวมระดับเดือน | ยอดรายได้จริง, เป้าหมาย, ค่าใช้จ่าย, อัตราการเติบโต เทียบรายเดือน/รายปี |
| **⏱️ ติดตามรายสัปดาห์ (Weekly)** | ติดตามยอดและประเมินผลงานแบบสัปดาห์ต่อสัปดาห์ | ยอดผลงานรายวัน (รส.201 + Pickup), เทียบเป้าหมายถัวเฉลี่ยรายสัปดาห์ (ศุกร์–พฤหัสบดี) |
| **🏢 ลูกค้ารายใหญ่ (Customer)** | วิเคราะห์แนวโน้มรายได้ระดับลูกค้ารายสำคัญ | ยอดใช้บริการของลูกค้ารายใหญ่และคู่ค้าสำคัญในพื้นที่ |

## 🔍 3. การกรองข้อมูล (Filter & Search)
ผู้ใช้งานสามารถเลือกดูข้อมูลเฉพาะเจาะจงได้จากแถบตัวกรองด้านบน:

1. **เลือกช่วงเวลา (Date / Time Range):**
   * *มุมมองรายเดือน:* เลือก ปี พ.ศ. และ เดือน ที่ต้องการดู
   * *มุมมองรายสัปดาห์:* เลือกช่วง วันที่เริ่มต้น – วันที่สิ้นสุด (ระบบจะคำนวณเป้าหมายและผลงานเฉพาะช่วงที่เลือกให้อัตโนมัติ)
2. **เลือกพื้นที่ / สังกัด:**
   * **ทุกจังหวัด (เขต 6):** แสดงผลรวมทุกจังหวัดในสังกัดเขต 6
   * **รายจังหวัด:** เลือกจังหวัดที่ต้องการ (เช่น พิษณุโลก, นครสวรรค์, สุโขทัย ฯลฯ)
   * **รายที่ทำการ:** เมื่อเลือกจังหวัดแล้ว สามารถเจาะจงดูเฉพาะที่ทำการไปรษณีย์รายแห่งได้

## 📈 4. การอ่านค่าและวิเคราะห์ผลบนหน้าจอ

### 4.1 แถบสรุปตัวเลขหลัก (KPI Scorecards)
* **ยอดรายได้รวม (Actual Revenue):** ยอดเงินรวมที่ทำได้จริงในช่วงเวลาที่เลือก
* **เป้าหมาย (Target):** เป้าหมายรายได้ที่กำหนดไว้
* **บรรลุเป้าหมาย (% Achievement):** สัดส่วนผลงานจริงเทียบเป้าหมาย
  * 🟢 **สีเขียว:** ทำผลงานได้เกิน 100% (เกินเป้าหมาย)
  * 🟡 **สีเหลือง/ส้ม:** ทำผลงานได้ระหว่าง 80% – 99.9%
  * 🔴 **สีแดง:** ทำผลงานได้ต่ำกว่า 80%
* **เติบโตเมื่อเทียบกับปีก่อน (% YoY Growth):** ทิศทางผลงานเทียบกับช่วงเดียวกันของปีก่อนหน้า

### 4.2 มาตรวัดประสิทธิภาพรวม (Performance Gauge)
* แสดงระดับความก้าวหน้าของผลงานสะสมปัจจุบันเทียบกับแนวทาง Fibonacci / จุดปลอดภัยของเป้าหมาย

### 4.3 สัดส่วนตามกลุ่มธุรกิจ (Business Group Breakdown)
* กราฟวงกลมและแท่งจำแนกโครงสร้างรายได้ตาม 6 กลุ่มบริการ:
  1. บริการขนส่งและโลจิสติกส์ (EMS, พัสดุ, Pickup, Fuze)
  2. บริการไปรษณียภัณฑ์ (จดหมาย, ของตีพิมพ์)
  3. บริการค้าปลีกและการเงิน (COD, สินค้าหน้าร้าน, ธนาณัติ)
  4. บริการระหว่างประเทศ
  5. บริการอื่นๆ / รายได้อื่น

### 4.4 การจัดอันดับที่ทำการ (Ranking & Leaderboard)
* จัดอันดับที่ทำการไปรษณีย์ที่มีผลงานยอดเยี่ยมสูงสุด และที่ทำการที่ต้องการการเร่งรัดยอด

### 4.5 บทวิเคราะห์อัจฉริยะ (AI Insight Panel)
* กล่องข้อความสรุปไฮไลต์สำคัญ สรุปจุดเด่น ปัญหา และโอกาสทางธุรกิจ เพื่อนำไปใช้ประกอบการประชุมบริหารได้ทันที

## 💾 5. การส่งออกข้อมูลและการบันทึกรูปภาพ (Export & Share)
ที่มุมบนขวาของหน้าจอ มีเครื่องมืออำนวยความสะดวก 2 ปุ่ม:

* 📷 **ปุ่มรูปกล้อง (Capture Image):** 
  คลิกเพื่อบันทึกภาพหน้าจอแดชบอร์ดทั้งหมดออกมาเป็นไฟล์รูปภาพ PNG คุณภาพสูง คมชัด เหมาะสำหรับแนบลงในไลน์กลุ่ม หรือใส่ในสไลด์ PowerPoint นำเสนอ
* 📊 **ปุ่ม Excel (Export Data):** 
  คลิกเพื่อดาวน์โหลดตารางข้อมูลสรุปออกมาเป็นไฟล์ Excel (.xlsx) เพื่อนำไปคำนวณหรือจัดทำรายงานเพิ่มเติม

---

## 📂 6. คู่มือสำหรับผู้ดูแลข้อมูล (Data Administrator Checklist)
เมื่อมีไฟล์ข้อมูลชุดใหม่ (เช่น สิ้นเดือน หรือ สิ้นสัปดาห์):

1. นำไฟล์ `.json` ใส่ลงในโฟลเดอร์ `database/`
2. **หากเป็นข้อมูลรายเดือนใหม่:** รันคำสั่ง `npm run upload database/ชื่อไฟล์.json`
3. **หากเป็นข้อมูลรายสัปดาห์ใหม่ (รส.201 / Pickup):** รันคำสั่ง `npm run upload:weekly`
4. ข้อมูลบนหน้าแดชบอร์ดจะอัปเดตให้อัตโนมัติทันที
